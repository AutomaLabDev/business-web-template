# Business Web Template

Plantilla web responsive para pequeños negocios y profesionales locales.

El proyecto está pensado como una base reutilizable para crear páginas web comerciales de una sola página de forma rápida, adaptando principalmente la identidad del negocio, los textos, los servicios, las imágenes y los datos de contacto.

## Demo actual

La plantilla está actualmente adaptada como ejemplo para una empresa ficticia de reformas:

**Reformas Sur Madrid**

Demo publicada con GitHub Pages:

https://automalabdev.github.io/business-web-template/

---

## Características

- Diseño responsive para móvil, tablet y ordenador.
- Navegación mediante secciones.
- Menú hamburguesa en dispositivos móviles.
- Hero principal con llamadas a la acción.
- Sección de servicios con imágenes.
- Sección sobre el negocio.
- Elementos de confianza y experiencia.
- Opiniones de clientes.
- Sección de presupuesto/contacto.
- Acceso directo a teléfono.
- Acceso directo a WhatsApp.
- Acceso directo a correo electrónico.
- Footer con navegación y datos de contacto.
- Diseño basado en variables CSS para facilitar cambios de identidad visual.
- Sin frameworks ni dependencias externas.

---

## Tecnologías

El proyecto utiliza únicamente:

- HTML5
- CSS3
- JavaScript

Esto mantiene la web ligera, sencilla de mantener y fácil de alojar prácticamente en cualquier servicio de hosting.
